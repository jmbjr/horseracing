# Scratched — Horse Racing

A phone-first, pass-and-play version of the wooden horse racing dice game. It automatically deals cards, scratches horses, tracks chips, balances lane lengths by dice probability, and saves an unfinished race on the device.

## Play

Open the GitHub Pages site on Android in Chrome. Use **Add to Home screen** or **Install app** for a fullscreen, offline-capable version.

## Rules

- 2–8 players; two dice; virtual cards and chips.
- Four unique horses are scratched before racing.
- Scratch penalties rise from 1× through 4× the selected base bet.
- A dice total advances its matching horse one space.
- Each card matching the winning horse receives one quarter of the pot.

All state remains in the browser; the game sends no player information anywhere.
